# PLACEHOLDER ART: NOT FOR RELEASE

Everything in this folder is temporary art for the alpha. Every manifest entry
that points here is tagged `"placeholder": true`, and the release check lists
them (Stage 6).

Sources, authors and licences for anything here are listed in `/CREDITS.md`.
Final art goes in the matching category folder (`characters`, `enemies`,
`icons`, `backgrounds`, `ui`). Once it's there, update the manifest path and drop the
`placeholder` flag.
